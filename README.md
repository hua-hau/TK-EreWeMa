# TikTok 二维码常驻（Chrome 插件，支持 FastMoss / 郑和数据）

让 **FastMoss（fastmoss.com）** 和 **郑和数据（tk.zhenghedata.com / www.zhenghedata.com）** 商品页的 TikTok 扫码二维码**自动弹出、一直保持展开**：
- 打开商品页**不用碰鼠标**，二维码自动弹出来；
- 不会因为鼠标移开、页面切换而自动关闭；
- 并会复制一份到**右下角悬浮窗口**，跟随滚动始终可见，方便随时用手机 TikTok 扫码。

## 功能

| 功能 | 说明 |
| --- | --- |
| 自动弹出二维码 | 打开商品页后自动找到二维码按钮并模拟鼠标移入/移动触发，免去手动操作（默认开启）。FastMoss 的二维码按钮是纯图标无文字（按二维码网格图标特征识别）；郑和数据的标题旁有 26px 小二维码图标，**插件直接把小图放大到悬浮窗**，即使页面弹窗不弹出也保证二维码可用，同时仍尝试触发页面大弹窗 |
| 阻止二维码自动关闭 | 二维码弹出后强制保持展开（display:flex !important 覆盖隐藏），反复阻止页面把它收起 |
| 弹窗被移除后自动重开 | 若页面把弹窗整个删掉（如切换数据），冷却后自动重新触发，二维码再弹出来 |
| 悬浮置顶显示 | 自动复制一份二维码到右下角悬浮窗，滚动页面也不消失，拖动标题栏可移动，点 ✕ 关闭 |

## 安装步骤（零基础版）

1. 解压你下载的 zip 包，得到一个名为 `fastmoss-qr-keep` 的文件夹。
   **注意：解压时选一个新文件夹，不要解压到插件文件夹内部，也不要产生嵌套的 `fastmoss-qr-keep/fastmoss-qr-keep` 两层目录。**
2. 打开 Chrome 浏览器，在地址栏输入 `chrome://extensions` 并回车。
3. 打开页面**右上角**的「开发者模式」开关（Developer mode）。
4. 点击页面左上角出现的「加载已解压的扩展程序」（Load unpacked）。
5. 选择第 1 步解压出的 `fastmoss-qr-keep` 文件夹（要选到里面直接能看到 `manifest.json` 的那一层）。
6. 加载成功后，Chrome 工具栏会出现一个二维码图标，安装完成。
7. 打开 FastMoss 或郑和数据的商品详情页，**刷新一次页面**，二维码自动弹出，右下角出现悬浮窗。

## 使用方法

1. 打开任意 FastMoss / 郑和数据的商品详情页。
2. 不用碰鼠标：插件自动识别二维码按钮/图标并模拟触发，二维码随即保持展开，右下角同时出现悬浮二维码窗，滚动页面也一直在。
3. 用手机 TikTok 对准扫码即可；悬浮窗可拖动到任意位置，点 ✕ 可关闭。
4. 点 Chrome 工具栏的插件图标，可开关「自动弹出 / 阻止自动关闭 / 悬浮置顶」等选项，设置即时生效。

## 常见问题

- **郑和数据上没自动弹出**：确认在商品**详情页**（页面标题旁有小二维码图标）；确认已登录郑和数据；安装后刷新一次页面。郑和数据的弹窗是鼠标移到小图标上才显示，插件会自动模拟移动触发。
- **页面没自动弹出二维码**：如果页面布局特殊导致识别不到，手动把二维码弹出来一次，悬浮窗会立刻出现并常驻；也可以刷新页面再试。
- **误触发了其他图标**：自动触发只针对二维码特征的图标；如仍有疑虑可在插件面板关闭「自动弹出二维码」。
- **不生效**：确认当前页面在 fastmoss.com 或 zhenghedata.com；安装后刷新一次商品页；确认扩展开关为开启。
